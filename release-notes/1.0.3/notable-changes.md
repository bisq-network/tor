# Tor Library 1.0.3 Notable Changes

- Updated the Tor Browser Expert Bundle from 16.0.1 to 16.0.3 and Tor from 0.4.9.16 to 0.4.9.17. [Tor Browser 16.0.3 release announcement](https://blog.torproject.org/new-release-tor-browser-1603/)
- Updated the signed SHA-256 checksums for Linux x86_64 and ARM64, macOS x86_64 and ARM64, and Windows x86_64.
- Updated the Java, Gradle and CodeQL actions used by CI.

See the [full release notes](full-release-notes.md) for release history and verification details.
