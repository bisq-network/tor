# Tor Library 1.0.3 Highlights

The Tor library now bundles Tor 0.4.9.17 from the Tor Browser 16.0.3 Expert Bundle. Tor 0.4.9.17 is an upstream security release that strengthens relay denial-of-service defenses, including IPv6 handling. [Tor Project security release announcement](https://forum.torproject.org/t/security-release-0-4-9-17/22454)

See the [notable changes](notable-changes.md) and [full release notes](full-release-notes.md) for platform coverage and release history.
